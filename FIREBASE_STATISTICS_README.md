## 🔧 Как это работает

### Процесс сохранения результатов

1. **Пользователь проходит тест**
   - Отвечает на все вопросы
   - Видит результаты

2. **Автоматическое сохранение**
   - При завершении теста вызывается `saveTestResult()`
   - Функция проверяет авторизацию пользователя
   - Если пользователь авторизован, результаты сохраняются в Firestore

3. **Структура данных в Firebase**
   ```
   users/{userId}/lessonProgress/{lessonId}
   {
       lessonId: "module-1-lesson-1",
       completed: true,
       score: 87.5,
       correctAnswers: 7,
       totalQuestions: 8,
       completedAt: timestamp,
       lastAccessed: timestamp
   }
   ```

4. **Просмотр статистики**
   - Пользователь открывает [statistics.html](statistics.html)
   - Страница загружает все результаты из Firebase
   - Отображает статистику по модулям с цветовой индикацией

### Цветовая индикация результатов

- 🟢 **90-100%** - Отлично (зелёный)
- 🟡 **75-89%** - Хорошо (светло-зелёный)
- 🟠 **60-74%** - Средне (оранжевый)
- 🔴 **0-59%** - Плохо (красный)
- ⚪ **Не пройден** - Серый

## 🔐 Авторизация

### Для разработчиков

#### Добавление нового теста

Если нужно добавить новый тест в систему:

1. Создайте HTML-файл теста по образцу существующих
2. Добавьте в `<script>`:
```javascript
<script type="module">
    import { saveTestResult } from '../../../src/firebase/firebase-test-integration.js';
    
    const lessonId = 'module-X-lesson-Y'; // Укажите правильный ID
    
    // ... ваш код теста ...
    
    function showResults() {
        // ... расчёт результатов ...
        
        // Сохранение в Firebase
        saveTestResult(lessonId, percentage, correctAnswers, totalQuestions);
    }
</script>
```

3. Обновите список тестов в [statistics.html](statistics.html) в массиве `allTests`

## 🔍 Отладка

### Проверка сохранения результатов

1. Откройте консоль браузера (F12)
2. Пройдите тест до конца
3. Должно появиться сообщение:
   - ✅ `Результаты сохранены для пользователя: user@example.com`
   - ⚠️ `Результаты не сохранены: Пользователь не авторизован`

### Проверка в Firebase Console

1. Откройте [Firebase Console](https://console.firebase.google.com/)
2. Выберите проект "russian-orthography-course"
3. Перейдите в Firestore Database
4. Найдите коллекцию `users/{userId}/lessonProgress`
5. Проверьте документы с результатами тестов
