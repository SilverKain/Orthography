# 🚀 Как запустить проект локально

## Проблема

Если страницы открываются через `file://` (двойной клик на HTML-файле), то модули ES6 не работают и Firebase не подключается.

## Решение: Запуск через локальный сервер

### Вариант 1: Vite (рекомендуется)

1. Откройте терминал в папке проекта
2. Запустите команду:
   ```bash
   npm run dev
   ```
3. Откройте браузер по адресу: `http://localhost:5173` (или порт, который показан в терминале)

### Вариант 2: VS Code Live Server

1. Установите расширение "Live Server" в VS Code
2. Откройте любой HTML-файл (например, `index.html`)
3. Нажмите правой кнопкой мыши и выберите "Open with Live Server"
4. Страница откроется автоматически в браузере

### Вариант 3: Python HTTP Server

1. Откройте терминал в папке проекта
2. Запустите команду:
   ```bash
   python -m http.server 8000
   ```
3. Откройте браузер по адресу: `http://localhost:8000`

### Вариант 4: Node.js http-server

1. Установите http-server глобально (один раз):
   ```bash
   npm install -g http-server
   ```
2. Запустите в папке проекта:
   ```bash
   http-server
   ```
3. Откройте браузер по адресу, который показан в терминале

## Тестирование Firebase интеграции

1. Запустите локальный сервер (любым из способов выше)
2. Откройте: `http://localhost:ПОРТ/test-firebase.html`
3. Проверьте логи в окне браузера

Ожидаемый результат:
- ✅ Firebase успешно инициализирован
- ✅ или ⚠️ Статус авторизации
- Кнопки для тестирования сохранения данных

## Страницы для тестирования

- **Главная**: `http://localhost:ПОРТ/index.html`
- **План курса**: `http://localhost:ПОРТ/course-plan.html`
- **Статистика**: `http://localhost:ПОРТ/statistics.html`
- **Тест Firebase**: `http://localhost:ПОРТ/test-firebase.html`
- **Любой тест**: `http://localhost:ПОРТ/theory/modules/practice/module-1-lesson-1-test.html`

## Проверка работы статистики

1. Авторизуйтесь на главной странице
2. Пройдите любой тест до конца
3. Откройте страницу статистики
4. Убедитесь, что результаты отображаются

## Отладка

Если что-то не работает, откройте консоль браузера (F12) и проверьте ошибки:
- Красные сообщения об ошибках
- Network tab - проверьте, загружаются ли модули Firebase
- Console tab - смотрите логи подключения и сохранения данных
